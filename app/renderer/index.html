Coding supervisor

When the Coding supervisor app is on (Tool Hub), you can say "Jarvis, add a login page to my project". Jarvis runs Claude Code on the folder you pick, in the background, brings you its questions with its own recommendation, and gives you updates.

At every level these always come to you: deleting files, git push, installing software, using the network, anything outside the project folder, and files with keys or passwords.

This adds two small entries (marked "jarvis-claude-hook") to your Claude Code settings file; turning it off removes exactly those. A copy of the original file is kept next to it.
