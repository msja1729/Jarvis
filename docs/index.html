Jarvis: A Personal Team of AI Experts

Jarvis project · November 2026 · version 0.8.1

Jarvis is a Windows desktop app that turns Claude into a small team of specialist assistants who live on the computer: they are spoken to from any app, can hear meetings and see the screen, remember the user in their own field, and act in the user's apps only within rules the user sets. This review states where that makes Jarvis better than existing agents, and where it does not.

What Jarvis is

Jarvis gives the user four AI specialists, each with a name, a voice, a field and a memory of their own. The user talks to them by name ("Sara, I've had a headache since yesterday") and stays with that member until naming another.

RyanProject manager and tech lead: projects, meetings, coding"Ryan, add a login page to my project"
SaraHealth coach: symptoms, lab reports, food, sleep"Sara, what should I eat for dinner?"
VictorMoney and business: budgets, debt, bills, investing basics"Victor, help me make a monthly budget"

A fifth role, Jarvis itself, is the front desk: it passes each request to the right member. The members ask each other for help when a request crosses fields.

Where Jarvis is genuinely better

Jarvis does not have a better model: it runs on Claude itself. Its advantage is everything built around the model, which general assistants (Claude, ChatGPT) and coding agents (Claude Code, OpenAI Codex) do not offer together.

1. It lives on the computer, not in a window. A global push-to-talk key works in any app, and the answer is spoken back while the user keeps working; music pauses on its own. Speech recognition (whisper.cpp) and the natural voices (Kokoro) run on the computer, so no audio leaves it. Other agents are used inside their own window, browser tab or terminal.

2. It can hear and see what the user is working on. It records a meeting's microphone, the computer's sound and the screen together, captures each new slide, and turns it all into minutes, tasks and reminders. During a lecture or a call the user can ask "what did he just say?". Other agents know only what the user pastes or uploads.

3. Permissions are enforced in code, per expert and per action. Every tool call passes a gateway that decides by app, by expert and by kind of action: reading is allowed, changes ask first, deleting or paying always asks. An expert cannot even see an app it is not allowed to use, and every action is logged. Claude and Codex approve tools or commands, but have no way to say "the health expert may never touch my email".

4. Specialists with a method and a memory of their own. Each expert follows its field's procedure: red-flag checks first in health, the user's investment policy before any money decision, a written spec before any coding. Each keeps structured files about the user (lab history, balance sheet, roadmap) in a folder the user can open and correct. General assistants keep one short, general memory; coding agents keep instruction files per project.

5. It speaks up at the right time. Spoken reminders, medicine schedules for the exact number of days, a morning plan and an evening review. Chat assistants and coding agents answer only when asked.

6. Coding agents, supervised for non-programmers. Ryan runs Claude Code in the background, handles routine questions itself, brings the user only real decisions with a recommendation, and reports progress by voice. Some rules can never be switched off: deleting files, git push, installing software, network use and anything outside the project always come to the user. With raw Claude Code or Codex, the user watches a terminal and judges every step alone.

How it works

The front desk sends each request to the right expert, who thinks with Claude on the user's own plan; before any tool or app is used, the permission gateway allows it, asks the user, or blocks it, and the answer is spoken and written back.

Honest limits

  • Not a smarter model. On pure reasoning or coding, Jarvis is exactly as good as the Claude model underneath; it does not out-code Claude Code or Codex.
  • Depends on Anthropic. It needs Claude Code and a Claude Pro or Max plan, and its use counts against that plan's limits.
  • Information, not professionals. The health and money experts follow careful playbooks, but give information, not a diagnosis or regulated financial advice; the playbooks have not yet been reviewed by professionals.
  • Not yet formally measured. Its advantage over plain Claude has been checked by hand, not in a side-by-side evaluation.
  • Desktop and Windows only. There is no phone app; the installer is not code-signed; fast speech recognition needs an NVIDIA graphics card, and a spoken answer starts about 3.5 to 5.5 seconds after the user stops talking.
  • Apps come from Claude's directory. Outside apps are limited to claude.ai's connectors (for example, personal Outlook.com addresses are not supported).
